# Troubleshooting

## npm 404 Error
Command:
npx owasp-juice-shop

Error:
Package not found

Fix:
Downloaded Juice Shop manually from GitHub.

## ENOENT package.json Error
Error:
Could not read package.json

Cause:
Running npm start in wrong directory

Fix:
Navigated to correct folder.

## ZIP Extraction Issue
Issue:
Tried running before extracting

Fix:
Extracted files before running.

## Key Lesson
Most errors were setup-related. Understanding file structure is critical.
