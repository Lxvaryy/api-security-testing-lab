# Setup Guide

## Install Node.js
Download: https://nodejs.org/

Verify installation:
node -v
npm -v

## Download OWASP Juice Shop
Download:
https://github.com/juice-shop/juice-shop/releases

Select the version that matches your system and Node.js version.

## Extract Files
Right-click the downloaded file and click "Extract All".

## Run the Application
Open the extracted folder.

Make sure you are inside the folder that contains package.json.

Run:
npm start

If successful, you should see:
Server listening on port 3000

## Access the Application
Open your browser and go to:
http://127.0.0.1:3000

## Notes
- If you get ENOENT error, you are in the wrong folder
- Make sure files are extracted before running
