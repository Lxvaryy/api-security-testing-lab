# Lessons Learned

This project helped me understand API security through hands-on experience.

I learned how web applications communicate using APIs and how tools like Burp Suite and Postman are used to analyze traffic.

Intercepting login requests showed how sensitive data can be exposed if not properly secured.

I also learned how to filter large amounts of traffic, identify important requests, and modify them to test application behavior.

Additionally, troubleshooting setup issues improved my problem-solving skills.

Overall, this project gave me a strong foundation in web application and API security.
